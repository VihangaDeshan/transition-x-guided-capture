# Agent guide (Antigravity, Claude, Copilot …)

This repo implements the **Guided Capture Technical Design Document v1.0** for Rysera Innovations.
Read `README.md` and `docs/CONTRACTS.md` before changing anything.

## Architecture rules (do not break)
1. React Native (Expo SDK 54, RN 0.81.5, New Architecture) owns UI, state, strings and transfer.
   ARCore, per-frame work, recording and the decision engine stay in Kotlin (`modules/guided-capture`).
2. Packages `core`, `signals`, `guidance`, `replay`, `export` under
   `modules/guided-capture/android/src/main/java/lk/transitionx/capture/` must not import
   `android.*`, `androidx.*`, `com.google.ar.*`, `expo.*` or `com.facebook.*`. CI compiles them on a
   plain JVM (`tools/engine-tests`) and a Jest test greps for it.
3. The engine never reads a clock: time is a parameter. Keep it deterministic.
4. GuidanceState carries a rule ID; text lives only in `src/i18n/strings.ts` (en + si).
5. Thresholds are data: change `config/thresholds.v1.json` and bump its `version`, not Kotlin constants.
6. `android/` and `ios/` are generated by `expo prebuild` — never commit or hand-edit them.
   Native config goes in `app.json` or the module's `android/` folder.
7. Do not add Expo Router or other navigation libraries; `App.tsx` switches three screens.
8. Only permissively licensed dependencies (Apache-2.0 / MIT / BSD). `npm run licenses` checks.
9. Pin exact versions. Use `npx expo install` for Expo/RN packages so versions match SDK 54.

## Verify before you say "done"
```bash
npm run check                         # tsc + jest
gradle -p tools/engine-tests test     # Kotlin engine tests (JDK 17)
```
Then push: GitHub Actions builds the APK and publishes it under Releases. A red Android job means
the Kotlin/Android code does not compile — read the job log, fix, push again.
